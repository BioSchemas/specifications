## Profile
This [profile](https://bioschemas.org/profiles/LearningPath) provides a structured sequence of learning activities, resources, and assessments designed to guide a learner from basic concepts to advanced skills.

### Example Markup

This repository contains example markup for the LearningPath profile generated by the [Training group](http://bioschemas.org/groups/Training/). Examples are purely illustrative and may use fictional data.

Examples should be stored in a subfolder indicating which version of the profile it is valid for. Please check to ensure the example you are reading matches the version of the profile you are interested in.
